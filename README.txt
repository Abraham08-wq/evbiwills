EvBwills WEBSITE — how to put it online
=========================================

Files:
  index.php  - the website page (you don't need to touch this)
  data.php   - YOUR settings: phone number, products, prices. Edit this one.
  images/    - product photos. Add new photos here and list them in data.php ($products).

To change products or add prices:
  Open data.php in any text editor. Find the item and type a price, e.g.
     ['name' => 'Sneakers', 'price' => 'KSh 2,500'],
  Save and upload again.

To put it online:
  1. Buy cheap PHP hosting + a domain (e.g. evbwills.co.ke) from a Kenyan host
     such as Truehost, HostPinnacle or Safaricom web hosting.
  2. Open the hosting "File Manager" -> public_html folder.
  3. Upload index.php and data.php there.
  4. Visit your domain — done.

The order form opens WhatsApp on the customer's phone with the order already
